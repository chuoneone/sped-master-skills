> 專為**國中特殊教育（特教資源班）、適性教學與差異化學習**打造的頂尖 AI 備課大師技能套組（Skills for Antigravity & AI Coding Assistants）。
> 核心目標是**精準降載、消除書寫障礙、直觀視覺錨點**，並一鍵生成**「教師大屏投影教學 ＋ 學生端純淨 A4 實體列印」雙模式一體化教材**。

---

## 🌟 核心理念與雙模式技術

傳統教材往往充斥大量文字、複雜文法術語或機械式繁重抄寫，對特教生造成極大認知負荷。本技能庫秉持以下核心理念：

1. **雙模式一體化（Dual-Mode Ready）**：
   - 🧑‍🏫 **教師端（大屏／電子白板）**：逐題點擊顯示答案、一鍵揭曉全篇、4 色板書畫筆圈記、大字級高對比度。
   - 👨‍🎓 **學生端（A4 純淨紙本列印）**：按下 `Ctrl + P` 即刻還原為白紙黑字作業評量卷，自動隱藏所有解答、按鈕與操作干擾。
2. **極致降載與視覺錨點**：
   - 採用皮克斯 3D 溫暖情境插圖、直觀圖解錨點、篇章結構對照表（Graphic Organizer）。
   - 嚴格統一中文「芫荽體 (Iansui)」、全文 14pt 大字級、零廢話引導。
3. **拒絕死記硬背式評量**：
   - 英文禁用全課單字翻譯手寫考卷；數學純算式零國字並採五階褪除鷹架；國文精讀逐段雙頁循環。

### 1. 📚 sped-chinese-master（國中特教國文備課大師）
專為國中特教國語文設計的旗艦級 30 頁雙模式備課電子書：
- **作家探索檔案（2 頁）**：以 FB 社群個人檔案方式生動呈現作家生平與背景。
- **課文逐段雙頁循環精讀（每段嚴格 2 頁，共 10 段 20 頁）**：
  - **奇數頁（閱讀與生字）**：左欄溫暖插圖、右欄課文原文與易讀版對照；底部附 `Bpmf Zihi Kai Std` 芫荽注音田字格生字練寫。
  - **偶數頁（深究與檢核）**：課文句意深究、修辭圖解專區、2 題即時選擇檢核（點擊顯答案）。
- **課文重點脈絡統整表（1 頁）**：全篇結構圖、起承轉合思維導圖。
- **獨家字族文辨析專題（固定 5 組，每組 1 頁 A4）**：聲旁形旁拆解、同偏旁字族短文、特教防混淆認讀。
- **課後隨堂綜合評量（2 頁）**：圖文連連看、精選會考改寫選擇、生活情境反思。

### 2. 📐 sped-math-master（國中特教數學備課大師）
深度整合「1-3 先有觀念說明與解題原則」與「1-2 適性學習單之五階褪除鷹架」：
- **觀念聚焦（1~2 頁）**：白話核心概念、重點運算規則提示卡片、示範例題一步一算式。
- **五階漸進式練習題（3~5 頁）**：
  - **第 1 題（極高鷹架）**：黑字引導預填數，學生只需填入最後一步。
  - **第 2~4 題（逐步褪除）**：漸進式挖空中間運算算式。
  - **第 5 題（自主作答）**：3~4 行 `.write-space` 空白計算框，學生完全自主解題。
- **嚴格鐵則**：一行一個等號、純算式零國字干擾、KaTeX 數學式漂亮渲染、除號使用 `÷`、絕對值採用專屬定界符號避免混淆。

### 3. 🔤 sped-english-master（國中特教英文備課大師）
徹底擺脫生硬孤立的文法題庫，以「課文情境貫穿（Contextual Grounding）」為靈魂：
- **課堂講義整合電子書（標準 11 頁獨立 A4）**：
  - **P.1 故事起點**：引入課文對話第一幕（中英逐句對照）與情境字彙暖身。
  - **P.2~P.7 三大文法任務**：文法句型與人物 100% 來自課文對話，採「大圖解 ➔ 三階褪除練習」。
  - **P.8 單字積木重組**：直覺式點選重組，消除特教手寫抄寫負擔。
  - **P.9 篇章閱讀與 Graphic Organizer**：逐句中英對照 ＋ 篇章結構對照表（挖空 Word Bank）。
  - **P.10~P.11 對話與閱讀克漏字**：20~25 題二選一免手寫圈選式克漏字（正解亂數打散）。
- **單字隨堂學習單（每課 4 節，每節 2 頁 A4）**：均勻拆解單字，結合圖解認讀、看中拼英與情境圈選。
- **🚫 嚴禁傳統手寫考卷**：徹底杜絕 30~40 題全課單字翻譯手寫考卷（vocab-quiz）。

### 4. 📖 self-made-ebook（通用雙模式電子書基礎框架）
通用底層架構，適用於自然、社會、生活等各領域教材開發：
- 完整包含畫筆控制器（黑、紅、藍、螢光黃、粗細切換、一鍵清除）。
- 大屏互動功能（逐題點擊顯答、全書答案一鍵揭曉、全螢幕切換）。
- `@media print` 完美 A4 分頁與無干擾列印排版。

## 🚀 快速安裝與使用

### 方式 A：一鍵腳本安裝（PowerShell）

```powershell
# 複製儲存庫
git clone https://github.com/chuoneone/sped-master-skills.git
cd sped-master-skills

# 安裝至全域 Antigravity 設定 (~/.gemini/config/skills)
.\scripts\install-skills.ps1

# 或安裝至指定教學專案目錄
.\scripts\install-skills.ps1 -TargetWorkspace "c:\path\to\your\project"
```

### 方式 B：手動複製
將 `skills/` 資料夾內的各個技能資料夾，複製到：
- **全域環境**：`C:\Users\<帳號>\.gemini\config\skills\`
- **或個別專案**：`<你的專案根目錄>\.agent\skills\`
